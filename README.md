# کلاس درس مجازی — تکلیف تعاملی

وب‌اپلیکیشن فارسی (راست‌به‌چپ) با فونت وزیرمتن، ساخته‌شده با React + TypeScript + Vite.

صفحه اصلی یک کلاس درس در یک دبستان ایرانی را نشان می‌دهد: معلم کنار تخته و ۱۲ صندلی که هرکدام به یک دانش‌آموز اختصاص دارد. با کلیک روی هر صندلی، فرم ورود (نام کاربری و رمز عبور) باز می‌شود و پس از ورود موفق، تکلیف تعاملی (یک آزمون کوتاه چندگزینه‌ای) برای همان دانش‌آموز نمایش داده می‌شود.

## اجرا

```bash
npm install
npm run dev
```

## داده‌های دانش‌آموزان

اطلاعات نمونهٔ ۱۲ دانش‌آموز (نام، نام‌کاربری، رمز عبور) در `src/data/students.ts` قرار دارد. برای جایگزینی با اطلاعات واقعی، همین فایل را ویرایش کنید.

سوالات تکلیف تعاملی نیز در `src/data/homework.ts` قابل ویرایش است.
