# کلاس درس مجازی — تکلیف تعاملی

وب‌اپلیکیشن فارسی (راست‌به‌چپ) با فونت وزیرمتن، ساخته‌شده با React + TypeScript + Vite.

صفحه اصلی کلاس پایه سوم ابتدایی دبستان پسرانه تشیع ۲ را نشان می‌دهد: آموزگار کنار تخته و ۱۲ صندلی که هرکدام به یک دانش‌آموز اختصاص دارد. با کلیک روی هر صندلی، فرم ورود (نام کاربری و رمز عبور) باز می‌شود و پس از ورود موفق، دانش‌آموز با یک انیمیشن خوش‌آمدگویی وارد پروفایل خودش می‌شود و از آنجا می‌تواند تکلیف تعاملی هفتگی را انجام دهد.

## اجرا

```bash
npm install
npm run dev
```

## داده‌های دانش‌آموزان

اطلاعات نمونهٔ ۱۲ دانش‌آموز (نام، نام‌کاربری، رمز عبور) در `src/data/students.ts` قرار دارد. برای جایگزینی با اطلاعات واقعی، همین فایل را ویرایش کنید.

سوالات تکلیف تعاملی نیز در `src/data/homework.ts` قابل ویرایش است.

## پنل مدیر

با دکمهٔ «ورود مدیر» (بالای صفحه) می‌توان با نام‌کاربری و رمز عبور موجود در `src/data/admin.ts` وارد پنلی شد که وضعیت انجام تکلیف، نمره و زمان انجامِ هر ۱۲ دانش‌آموز را نشان می‌دهد. توجه: چون این یک سایت استاتیک بدون بک‌اند است، این اطلاعات فقط در مرورگر همان دستگاهی ذخیره می‌شود که دانش‌آموز با آن تکلیف را انجام داده است.
