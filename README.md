# کلاس درس مجازی — تکلیف تعاملی

وب‌اپلیکیشن فارسی (راست‌به‌چپ) با فونت وزیرمتن، ساخته‌شده با React + TypeScript + Vite.

صفحه اصلی کلاس پایه سوم ابتدایی دبستان پسرانه تشیع ۲ را نشان می‌دهد: آموزگار کنار تخته و ۲۰ صندلی که هرکدام به یک دانش‌آموز اختصاص دارد. با کلیک روی هر صندلی، فرم ورود (نام کاربری و رمز عبور) باز می‌شود و پس از ورود موفق، دانش‌آموز با یک انیمیشن خوش‌آمدگویی وارد پروفایل خودش می‌شود و از آنجا می‌تواند آزمون‌ها و فعالیت هفتگی را انجام دهد.

## اجرا

```bash
npm install
npm run dev
```

## داده‌های دانش‌آموزان

اطلاعات نمونهٔ ۲۰ دانش‌آموز (نام، نام‌کاربری، رمز عبور) در `src/data/students.ts` قرار دارد. برای جایگزینی با اطلاعات واقعی، همین فایل را ویرایش کنید.

توجه: چون سایت استاتیک است، نام‌کاربری و رمز عبور در فایل جاوااسکریپت منتشرشده قابل مشاهده‌اند. این ورود فقط برای شناسایی دانش‌آموز در کلاس است و امنیت واقعی ندارد — اطلاعات حساس را در آن‌ها قرار ندهید.

## آزمون‌ها و سؤالات

فهرست آزمون‌ها در `src/data/exams.ts` است و سؤالات هر آزمون در فایل مربوطه (`src/data/homework.ts` برای تکلیف هفتگی و `src/data/activities.ts` برای سؤالات حالت‌های ماده) نوشته شده است. هر سؤال این شکل را دارد:

```ts
{
  id: 1,
  question: "حاصل ۷ + ۵ کدام است؟",
  options: ["۱۱", "۱۲", "۱۳", "۱۰"],
  correctIndex: 1,   // شمارهٔ گزینهٔ درست، از صفر
}
```

آزمون‌هایی که فهرست `questions` آن‌ها خالی باشد در پروفایل قفل (🔒 به‌زودی) نمایش داده می‌شوند؛ با پر کردن سؤالات، خودبه‌خود باز می‌شوند.

فعالیت‌های اینترنتی (مثل فعالیت جامد، مایع، گاز) به‌صورت یک صفحهٔ خارجی درون یک پنجره باز می‌شوند و نشانی آن‌ها در همان `src/data/exams.ts` (فیلد `activityUrl`) قرار دارد. دانش‌آموز فقط با دکمهٔ «پایان فعالیت و ثبت» انجام شدن فعالیت را ثبت می‌کند؛ صرفِ باز و بسته کردن پنجره چیزی ثبت نمی‌کند.

صفحهٔ مستقل `activity-link.html` (یک لینک سادهٔ هم‌رسانی‌شدنی) در `public/` قرار دارد و در نشانی `/Rezvanazar/activity-link.html` در دسترس است.

## نتایج دانش‌آموزان

نتایج هر آزمون در حافظهٔ همان مرورگر (localStorage) با کلید `activity-log` ذخیره می‌شود و به هر دانش‌آموز بر پایهٔ شمارهٔ صندلی و شناسهٔ آزمون نگه داشته می‌شود. پنل مدیریتی جدا وجود ندارد؛ آموزگار نتایج را از طریق پیام‌رسان دریافت می‌کند.

## اطلاع‌رسانی به آموزگار (تلگرام و بله)

پس از ورود هر دانش‌آموز و پس از پایان هر آزمون، پیامی به گروه/گفتگوی آموزگار فرستاده می‌شود. توکن ربات‌ها در کد نوشته نشده و از متغیرهای محیطی خوانده می‌شود:

```
VITE_TELEGRAM_BOT_TOKEN   VITE_TELEGRAM_CHAT_ID
VITE_BALE_BOT_TOKEN       VITE_BALE_CHAT_ID
```

- اجرای محلی: فایل `.env.local` (از روی `.env.example`) بسازید. این فایل commit نمی‌شود.
- سایت منتشرشده: در GitHub به مسیر Settings → Secrets and variables → Actions بروید و چهار Secret با نام‌های `TELEGRAM_BOT_TOKEN`، `TELEGRAM_CHAT_ID`، `BALE_BOT_TOKEN`، `BALE_CHAT_ID` بسازید. فایل `/.github/workflows/deploy-pages.yml` آن‌ها را به build می‌دهد.

اگر توکنی قبلاً در کد یا تاریخچهٔ گیت commit شده باشد، آن توکن سوخته حساب می‌شود و باید ابطال شود (تلگرام: /revoke در BotFather).

این سایت استاتیک است؛ یعنی توکن در نهایت در باندل عمومی جاوااسکریپت قرار می‌گیرد. تنها راه پنهان‌ماندنِ واقعی توکن، عبور اطلاع‌رسانی از یک پراکسی سمت سرور (مثلاً Cloudflare Worker) است.

## انتشار

با هر push به شاخهٔ اصلی، GitHub Actions سایت را می‌سازد و روی GitHub Pages منتشر می‌کند (مسیر `/Rezvanazar/`).
