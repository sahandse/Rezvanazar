# پنل مدیریت Rezvanazar (cPanel)

## نصب
1. پوشه `admin` را در ریشهٔ سایت روی هاست کپی کنید.
2. در cPanel یک دیتابیس MySQL و کاربر بسازید و دسترسی کامل بدهید.
3. فایل `schema.sql` را در phpMyAdmin روی دیتابیس Import کنید.
4. فایل `config.example.php` را به `config.php` تغییر نام دهید و اطلاعات اتصال دیتابیس را وارد کنید.
5. در مرورگر `/admin/setup.php` را باز کنید و حساب مدیر را بسازید. پس از ساخت مدیر، setup به‌صورت خودکار قفل می‌شود.
6. از `/admin/login.php` وارد پنل شوید.

## ماژول‌ها
- داشبورد و آمار پایه
- مدیریت دانش‌آموزان (CRUD)
- آزمون/تکلیف (CRUD)
- مشاهده نتایج
- خروجی CSV سازگار با Excel

## نکته مهم اتصال سایت دانش‌آموزی
نسخه فعلی فرانت‌اند نتیجه‌ها را در localStorage ذخیره می‌کند. این پنل دیتابیس مستقل دارد؛ برای ثبت نتایج سراسری باید در مرحله اتصال، ارسال نتیجه از React به API امن PHP اضافه شود. تا آن زمان نتایج پنل فقط رکوردهای واردشده/ثبت‌شده در دیتابیس را نشان می‌دهد.
